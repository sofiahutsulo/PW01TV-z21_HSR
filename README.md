# PW1

Практична робота з розробки Android-застосунку для розрахунку характеристик палива.

## Опис

У межах даної практичної роботи мною було реалізовано простий мобільний застосунок на базі Android мовою Kotlin. Додаток призначений для обчислення складу сухої та горючої маси палива, а також нижчої теплоти згоряння за заданим елементарним складом робочої маси.

Також реалізовано перерахунок елементарного складу мазуту з горючої маси на робочу масу та визначення його нижчої теплоти згоряння.

## Функціонал

- розрахунок складу сухої та горючої маси палива;
- визначення нижчої теплоти згоряння для робочої, сухої та горючої маси;
- перерахунок складу мазуту з горючої маси на робочу;
- базова перевірка коректності введених даних.

## Технології

- Android
- Kotlin
- XML

## Запуск

Проєкт відкривається та запускається в Android Studio на емуляторі або реальному Android-пристрої.

## Примітка

Практичну роботу виконано відповідно до методичних вказівок. Коректність розрахунків перевірено на контрольних прикладах.
